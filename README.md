# Interview Studio 101

An application that let me practice doing coding questions alike Leetcode/Hackerrank but has the interview questions on one side, IDE editor on the other side, and store sessions, alike the sharepad.io as well. allow me to collaborate with friends (for mock interviews) and has a countdown (for individual practice) or a timer (both for individual practice and mock interview sessions). the stored sessions are static only, can only store all the information -- alike the snapshot option by sharepad.

This project was built with [Lovable](https://lovable.dev).
